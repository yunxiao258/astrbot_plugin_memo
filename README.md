# AstrBot 群聊备忘录与定时提醒插件

AstrBot 群聊/私聊备忘录与定时提醒插件：记录备忘、一次性/周期定时提醒、生日提醒（含农历）、倒计时、习惯打卡与稍后提醒。群聊与私聊会话各自独立，互不影响。

- 版本：1.0.0
- 许可证：MIT（详见 LICENSE）

## 功能

### 备忘录（`/备忘`）
- `/备忘 <内容>`：在当前会话记录一条备忘
- `/备忘 列表`：查看当前会话全部备忘（编号 + 内容 + 时间）
- `/备忘 删 <编号>`：删除指定编号的备忘
- 每会话上限 `max_memos` 条（默认 100），超限自动丢弃最旧

### 定时提醒（`/提醒`）
- `/提醒 HH:MM <内容>`：一次性提醒，到点推送到当前会话，触发后自动删除
- `/提醒 每天 HH:MM <内容>`：每日同一时间提醒，同一天只提醒一次
- `/提醒 每周 HH:MM <内容>`：每周同一时间提醒（未指定星期时默认为创建当天所在星期），同一周只提醒一次
- `/提醒 列表`：查看当前会话全部提醒（已触发的一次性提醒自动从列表移除）
- `/提醒 删 <编号>`：删除指定编号的提醒
- 每会话上限 `max_reminders` 条（默认 20），超限拒绝新增

### 生日提醒（`/生日`）
- `/生日 <名字> YYYY-MM-DD`：记录公历生日
- `/生日 <名字> 8月18日`：记录公历生日（简写格式）
- `/生日 <名字> 农历 八月十五`：记录农历生日（支持中文数字，如「农历 八月十五」「农历 腊月初八」）
- `/生日 列表`：查看当前会话全部生日记录
- `/生日 删 <编号>`：删除指定编号的生日记录
- 每年自动提醒：
  - 生日当天推送祝福 🎂
  - 默认提前 1 天预告 📢（`birthday_advance_days` 可配置，0 关闭预告）
- 农历支持：内置 1900-2100 年农历转换数据（`LUNAR_INFO`），农历生日按当年对应的公历日期提醒，每年自动换算

### 倒计时（`/倒计时`）
- `/倒计时 <名称> YYYY-MM-DD`：创建倒计时
- `/倒计时 列表`：查看当前会话全部倒计时（剩余天数 / 已到期）
- `/倒计时 删 <编号>`：删除指定编号的倒计时
- 每日定时播报剩余天数（默认 09:00，`countdown_push_time` 可配置，同日只播报一次）
- 到期当天推送提示并自动标记「已到期」，之后不再播报

### 习惯打卡（`/打卡`）
- `/打卡 加 <名称>`：创建习惯
- `/打卡 <名称>`：完成今日打卡
- `/打卡 列表`：查看当前会话全部习惯（连续天数、累计次数、最佳纪录、今日是否已打卡）
- `/打卡 删 <编号>`：删除指定编号的习惯
- 统计规则：
  - 昨日打过则连续天数 +1，否则重新从 1 计
  - 记录累计次数与历史最佳连续天数
  - 同日重复打卡不重复计数
- 晚间未打卡提醒：每晚定时提醒当天还没打卡的习惯（默认 22:00，`habit_remind_time` 可配置，`habit_remind_enabled` 可开关），当天只提醒一次

### 稍后提醒（`/稍后`）
- `/稍后 <时间短语> <内容>`：设置一次性临时提醒，到点推送
- 时间短语支持自然语言：
  - `5 分钟后`、`2小时后`（相对时间）
  - `明天 9 点`、`明天 18:30`（明天指定时刻）
  - `今晚 8 点`、`今天 15 点`（今晚 X 点且 X<12 视为晚上，如「今晚 8 点」= 20:00）
  - `18:30`、`8点半`、`15点`（绝对时刻）
- 示例：`/稍后 30分钟后 取快递`，30 分钟后推送提醒

### 后台提醒循环
- 插件加载/重载后自动启动后台任务，每隔 `check_interval` 秒（默认 60）检查一次所有到期提醒并推送
- 推送失败不记账，下一轮自动重试
- 一次性提醒触发后自动删除；每日/每周提醒按日期/周去重
- 数据以 JSON 原子写持久化，重启不丢失

## 配置

见 `_conf_schema.json`。关键项：

| 配置项 | 说明 | 默认 |
|--------|------|------|
| `check_interval` | 后台提醒检查间隔（秒） | 60 |
| `max_memos` | 每个会话最大备忘条数（超限自动丢弃最旧） | 100 |
| `max_reminders` | 每个会话最大提醒条数（超限拒绝新增） | 20 |
| `timeout_warn_seconds` | 一次性提醒预设时间超时容忍秒数（保留字段） | 300 |
| `birthday_advance_days` | 生日提前预告天数（0 关闭预告） | 1 |
| `countdown_push_time` | 倒计时每日播报时间（HH:MM，非法值回退 09:00） | 09:00 |
| `habit_remind_enabled` | 是否启用晚间未打卡提醒 | true |
| `habit_remind_time` | 晚间未打卡提醒时间（HH:MM，非法值回退 22:00） | 22:00 |

所有配置均为"脏值保护"：非法类型/非法值自动回退默认，不会导致插件崩溃。

## 数据

存储于 `plugin_data/astrbot_plugin_memo/`：

- `memos.json`：各会话备忘（按会话 UMO 分组）
- `reminders.json`：各会话提醒（按会话 UMO 分组）
- `birthdays.json`：各会话生日记录（按会话 UMO 分组）
- `countdowns.json`：各会话倒计时（按会话 UMO 分组）
- `habits.json`：各会话习惯打卡（按会话 UMO 分组）

数据以 JSON 持久化（临时文件 + 原子替换），重启后不丢失。
