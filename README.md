# AstrBot 群聊备忘录与定时提醒插件

AstrBot 群聊/私聊备忘录与定时提醒插件：记录备忘、一次性/周期定时提醒。群聊与私聊会话各自独立，互不影响。

- 作者：云晓
- 版本：1.0.0
- 许可证：MIT（详见 LICENSE）

## 功能

### 备忘录（`/备忘`）
- `/备忘 <内容>`：在当前会话记录一条备忘
- `/备忘 列表`：查看当前会话全部备忘（编号 + 内容 + 时间）
- `/备忘 删 <编号>`：删除指定编号的备忘

### 定时提醒（`/提醒`）
- `/提醒 HH:MM <内容>`：一次性提醒，到点推送到当前会话，触发后自动删除
- `/提醒 每天 HH:MM <内容>`：每日同一时间提醒
- `/提醒 每周 HH:MM <内容>`：每周同一时间提醒（默认为创建当天所在星期）
- `/提醒 列表`：查看当前会话全部提醒
- `/提醒 删 <编号>`：删除指定编号的提醒

后台循环每隔 `check_interval` 秒检查一次到期提醒，并推送到提醒所属会话（按会话 UMO）。

## 指令说明

| 指令 | 说明 | 权限 |
|------|------|------|
| `/备忘 <内容>` | 记录一条备忘 | 所有人 |
| `/备忘 列表` | 查看当前会话备忘 | 所有人 |
| `/备忘 删 <编号>` | 删除指定编号备忘 | 所有人 |
| `/提醒 HH:MM <内容>` | 一次性提醒 | 所有人 |
| `/提醒 每天 HH:MM <内容>` | 每日提醒 | 所有人 |
| `/提醒 每周 HH:MM <内容>` | 每周提醒 | 所有人 |
| `/提醒 列表` | 查看当前会话提醒 | 所有人 |
| `/提醒 删 <编号>` | 删除指定编号提醒 | 所有人 |

## 配置

见 `_conf_schema.json`。关键项：

| 配置项 | 说明 | 默认 |
|--------|------|------|
| `check_interval` | 后台提醒检查间隔（秒） | 60 |
| `max_memos` | 每个会话最大备忘条数（超限自动丢弃最旧） | 100 |
| `max_reminders` | 每个会话最大提醒条数（超限拒绝新增） | 20 |
| `timeout_warn_seconds` | 一次性提醒预设时间超时容忍秒数（保留字段） | 300 |

所有配置均为"脏值保护"：非法类型/非法值自动回退默认，不会导致插件崩溃。

## 数据

存储于 `plugin_data/astrbot_plugin_memo/`：

- `memos.json`：各会话备忘（按会话 UMO 分组）
- `reminders.json`：各会话提醒（按会话 UMO 分组）

数据以 JSON 持久化，重启后不丢失。

## 使用示例

```
/备忘 明天 10 点去银行
/备忘 列表
/备忘 删 1

/提醒 18:30 下班打卡
/提醒 每天 09:00 晨会
/提醒 每周 18:00 周报提交
/提醒 列表
/提醒 删 2
```
